## Run
Upload the entire folder to a GitHub repository and enable GitHub Pages from the repository root.

## Included
Customer storefront, product cards, cart, coupon/discount breakdown, checkout, PIN lookup, current location, payment UI, account pages, order tracking, admin login, product management, orders, customers, inventory, coupons, analytics, settings, and printable invoice.

## Important production note
This is a GitHub Pages/static demo architecture. LocalStorage is used for shared demo data in the same browser. Real multi-user accounts, secure admin authentication, database-backed orders, and real UPI/card payments require a backend/database/payment gateway. Never put real admin passwords or payment secrets in frontend code.
